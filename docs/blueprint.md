# **App Name**: Shiv Garment House

## Core Features:

- Curation Consultant: An AI-powered style tool that recommends matching garments based on selected fabric types and user occasions.
- Visual Textile Gallery: A high-fidelity grid layout showcasing premium cloth textures and garment details with zoom-in functionality.
- Fabric Category Explorer: Dynamic filtering system allowing users to sort inventory by material, weave, and traditional wear types.
- Intelligent Copywriter: An AI tool that generates descriptive storytelling for each garment, highlighting its craftsmanship and material origin.
- Collection Cart: A minimalist, side-panel shopping interface for managing selections without leaving the current view.
- Live Search Suggestions: Real-time search bar that provides instant visual garment matches as the user types.

## Style Guidelines:

- Primary color: Rich Terracotta (#CC5C33), chosen to evoke the warmth and heritage of artisanal textiles.
- Background: Charcoal Umber (#1D1917), a deep dark scheme that provides a sophisticated backdrop for vibrant fabric photography.
- Accent color: Dusky Rose (#D194A2), providing a gentle contrast for highlights and navigational elements.
- Headline font: 'Playfair', a high-contrast serif for an elegant, high-end boutique feel; Body font: 'PT Sans', a humanist sans-serif for clear readability in product details.
- A modular masonry-style layout for the gallery to accommodate different image aspect ratios of varied garment types.
- Thin-line, minimalist icons representing needlework, fabric weight, and tailoring services.
- Smooth parallax scrolling effects and elegant cross-fades when transitioning between fabric categories.
